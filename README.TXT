PROJECT TITLE: Galaxy BrickBreaker

PURPOSE OF PROJECT: The Project is a game designed to be like a futuristic type of BrickBreaker 
game

VERSION or DATE: Dec, 5 - Jan, 14

HOW TO START THIS PROJECT: Press the Run button to run the program, press the space button to 
start the game.

AUTHORS: Tristan and Azlan

USER INSTRUCTIONS: Run the program, you will be given a set of instructions if you press H and
if you press space, it will start the game instanly. Use the right and left arrow keys to move 
the paddle so the ball doesn't fall, keep breaking blocks to try and get a higher score, there 
will be a TNT block power ups which will explode in a 3 by 3 block radius upon impact, each 
block broken is worth 100 points, the levels will continue infinitly until you give up or your 
ball falls below where you will hit a gameover.
